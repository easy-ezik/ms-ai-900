# MS AI-900 학습 자료

Microsoft Azure AI Fundamentals (AI-900) 시험을 위한 학습 자료를 Docusaurus로 구성한 문서 사이트입니다.

## 🚀 시작하기

### 사전 요구사항

- Node.js 16.14 이상
- npm 또는 yarn

### 설치

```bash
# 의존성 설치
npm install
```

### 개발 서버 실행

```bash
# 개발 서버 시작 (http://localhost:3000)
npm start
```

### 빌드

```bash
# 정적 사이트 빌드
npm run build

# 빌드된 사이트 미리보기
npm run serve
```

## 📚 문서 구조

이 학습 자료는 다음 14개 주제로 구성되어 있습니다:

1. Azure의 AI 소개
2. Microsoft Foundry에서 AI 시작
3. 기계 학습 개념 소개
4. Azure에서 기계 학습 시작
5. 생성형 AI 및 Agent 소개
6. Microsoft Foundry에서 생성형 AI를 시작하기
7. 텍스트 분석 개념 소개
8. Microsoft Foundry에서 자연어 처리 시작
9. AI 음성 개념 소개
10. Microsoft Foundry에서 음성 시작
11. Computer Vision 개념 소개
12. Microsoft Foundry에서 Computer Vision 시작
13. AI 기반 정보 추출 개념 소개
14. Microsoft Foundry에서 AI 기반 정보 추출 시작
