# Microsoft Foundry에서 음성 시작 - 요약

## 핵심 개념
- **음성 인식 (음성-텍스트 변환)**: 말한 말을 텍스트로 기록
- **음성 합성 (텍스트-음성 변환)**: 텍스트를 음성으로 변환
- **Azure Speech Service**: 음성 인식 및 합성 기능 제공

## 음성 인식 프로세스
1. **음향 모델**: 오디오 신호를 음소로 변환
2. **언어 모델**: 음소를 단어로 매핑

## Azure Speech 기능
- **음성 텍스트 변환**
  - 실시간 전사: 오디오 스트림을 텍스트로 실시간 변환
  - 일괄 대화 내용 기록: 저장된 오디오 파일 비동기 전사
  - 사용자 지정 모델: 음향, 언어, 발음 모델 생성

- **텍스트 음성 변환**
  - 여러 언어 및 지역 발음 지원
  - 신경망 음성으로 자연스러운 음성 생성
  - 사용자 지정 음성 개발 가능

- **음성 번역**
  - 실시간 음성 언어 번역
  - 광범위한 원본 및 대상 언어 지원
  - 텍스트 또는 합성된 음성으로 번역 전달

## Azure Speech 사용 방법
- **스튜디오 인터페이스**: Microsoft Foundry 포털의 Speech Playground
- **CLI (명령줄 인터페이스)**
- **REST API 및 SDK**

## Azure 리소스
- **Speech 리소스**: Azure Speech만 사용하는 경우
- **Foundry 도구 리소스**: 다른 Foundry 도구와 함께 사용하는 경우
