Azure의 AI 소개 - 요약

생성 AI​

  • 정의: 새 콘텐츠를 생성하는 AI 분기
  • 기반: 대량의 데이터로 학습된 언어 모델
  • LLM vs SLLM: 큰 언어 모델은 강력하지만 비용 높음, 작은 언어 모델은 특정 영역에 집중

생성 AI 사용 사례​

  • 챗봇 및 AI 에이전트
  • 새 문서 또는 콘텐츠 만들기
  • 언어 간 텍스트 자동 번역
  • 복잡한 문서 요약 또는 설명

Computer Vision​

  • 이미지 분류: 이미지의 주 제목으로 레이블 예측
  • 개체 감지: 이미지에서 특정 개체 위치 식별
  • 의미 체계 구분: 개체에 속하는 개별 픽셀 식별
  • 다중 모달 모델: Computer Vision과 언어 모델 결합

Computer Vision 사용 사례​

  • 사진의 자동 캡션 또는 태그 생성
  • 시각적 검색
  • 소매 재고 모니터링
  • 보안 비디오 모니터링
  • 얼굴 인식 인증
  • 로봇 공학 및 자율 주행 차량

AI 음성​

  • 음성 인식: 음성을 텍스트로 변환
  • 음성 합성: 텍스트를 음성으로 변환

AI 음성 사용 사례​

  • 개인 AI 도우미
  • 통화 또는 모임 자동 전사
  • 비디오 또는 텍스트 오디오 설명 자동화
  • 언어 간 자동화된 음성 번역

NLP (자연어 처리)​

  • 엔터티 추출: 사람, 장소, 조직 등 식별
  • 텍스트 분류: 특정 범주에 문서 할당
  • 감정 분석: 긍정/부정/중립 확인
  • 언어 감지: 텍스트 언어 식별

NLP 사용 사례​

  • 통화 및 모임 문서 분석
  • 소셜 미디어 게시물 감정 평가
  • 챗봇 구현

데이터 및 인사이트 추출​

  • OCR (광학 문자 인식): 이미지에서 텍스트 위치 식별
  • 필드 추출: 문서의 개별 값 해석

데이터 추출 사용 사례​

  • 양식 및 문서 자동화 처리
  • 용지 양식 데이터 디지털화
  • 검색을 위한 문서 인덱싱
  • 모임 녹취록에서 핵심 요소 식별

책임 있는 AI 원칙​

  • 공정성: 편향 최소화 및 공정성 테스트
  • 안정성 및 안전성: 확률적 모델 고려, 위험 완화
  • 개인 정보 보호 및 보안: 학습 데이터 보호
  • 포용성: 모든 사용자 접근 가능
  • 투명성: 시스템 작동 방식 및 제한 사항 공개
  • 책임: 거버넌스 프레임워크 정의 및 적용
