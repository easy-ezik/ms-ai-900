Computer Vision 개념 소개 - 요약

핵심 개념​

  • Computer Vision: AI가 시각적 정보를 처리하는 분야
  • 이미지: 숫자 픽셀 값의 배열 (회색조 또는 RGB 채널)

Computer Vision 작업​

  1. 이미지 분류: 이미지 내용에 따라 텍스트 레이블 예측
  2. 객체 탐지: 이미지에서 개별 개체와 위치 검색 (경계 상자 좌표)
  3. 의미 체계 구분: 개체에 속하는 개별 픽셀 분류
  4. 상황별 이미지 분석: 멀티모달 모델로 이미지와 텍스트 간 관계 이해

이미지 처리​

  • 필터: 픽셀 값을 수정하여 시각적 효과 생성
  • 컨볼루션: 필터 커널을 이미지 전체에 적용

나선형 신경망 (CNN)​

  • 필터 계층: 이미지에서 숫자 기능 추출
  • 풀링 계층: 기능 맵 크기 축소
  • 완전히 연결된 신경망: 기능 값으로 레이블 예측
  • 출력 계층: 각 클래스에 대한 확률 값 생성

비전 트랜스포머 (ViT)​

  • 이미지 패치: 픽셀 값 패치를 벡터로 변환
  • 주의 기술: 패치 간 컨텍스트 관계 결정
  • 임베딩: 시각적 특징의 다차원 맵 생성

멀티모달 모델​

  • 언어와 비전 결합: 교차 모달 주의로 통합된 공간 표현
  • 이미지 설명: 시각적 특징 인식 및 연관된 언어 검색

이미지 생성​

  • 확산 기술: 프롬프트에서 관련 시각적 특징 식별
  • 반복적 생성: 노이즈 제거하여 이미지 구조 생성
  • 비디오 생성: 물리적 동작 및 임시 진행 고려
