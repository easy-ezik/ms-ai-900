Microsoft Foundry에서 AI 시작 - 요약

핵심 개념​

  • AI (인공 지능): 추론, 문제 해결, 인식, 언어 이해 등 인간 지능이 필요한 작업 수행
  • ML (기계 학습): 데이터 기반 알고리즘을 통한 AI 달성 방법
  • 딥 러닝: 여러 계층 신경망을 사용하는 ML의 특수 분기
  • 생성 AI: 새 콘텐츠를 만드는 딥 러닝 기능

주요 AI 워크로드​

  • 생성적 인공지능
  • 에이전트 및 자동화
  • Speech
  • 텍스트 분석
  • Computer Vision
  • 정보 추출

AI 애플리케이션 계층​

  1. 데이터 계층: 데이터 수집, 스토리지, 관리
  2. 모델 계층: ML/AI 모델 선택, 학습, 배포
  3. 컴퓨팅 계층: 모델 학습 및 실행 리소스
  4. 통합 및 오케스트레이션 계층: 모델과 데이터를 비즈니스 논리와 연결

Microsoft Foundry 구성 요소​

  • Foundry 모델: Azure OpenAI, 파트너 모델 등
  • 에이전트 서비스: 다단계 AI 워크플로 빌드 및 오케스트레이션
  • Foundry 도구: Azure 서비스 (비전, 언어, 검색, 문서 인텔리전스)
  • 거버넌스 및 관찰 가능성: ID, 정책, 모니터링

Azure 리소스 구조​

  • 테넌트: ID 및 액세스 관리
  • 구독: 청구 경계 및 서비스 액세스
  • 리소스 그룹: 관련 리소스 논리적 컨테이너
  • 리소스: 개별 서비스 또는 구성 요소

Foundry 프로젝트​

  • 프로젝트 생성: AI 애플리케이션 및 에이전트 빌드를 위한 작업 영역
  • 접근 가능한 기능: 모델 카탈로그, 플레이그라운드, 배포 도구, 관리 센터
