# Azure에서 기계 학습 시작 - 요약

## 기계 학습 프로세스 6단계
1. **문제 정의**: 모델이 예측할 대상과 성공 기준 결정
2. **데이터 가져오기**: 데이터 원본 찾고 액세스 권한 획득
3. **데이터 준비하기**: 데이터 탐색, 정리, 변환
4. **모델 학습**: 알고리즘 및 하이퍼 매개 변수 선택
5. **모델 통합**: 예측 생성을 위해 엔드포인트에 배포
6. **모델 모니터링**: 성능 추적

## 일반적인 기계 학습 작업
- **분류**: 범주 값 예측
- **회귀**: 숫자 값 예측
- **시계열 예측**: 미래 숫자 값 예측
- **컴퓨터 비전**: 이미지 분류 또는 개체 검색
- **NLP**: 텍스트에서 인사이트 추출

## 데이터 수집 및 준비
- **ETL/ELT**: 추출, 변환, 로드 프로세스
- **데이터 수집 파이프라인**: 데이터 이동 및 변환 작업
- **Azure 서비스**: Synapse Analytics, Databricks, Machine Learning

## 모델 학습 서비스
- **Azure Machine Learning**: 모델 학습 및 관리
- **Azure Databricks**: 분산 Spark 컴퓨팅
- **Microsoft Fabric**: 통합 분석 플랫폼
- **Foundry Tools**: 미리 빌드된 기계 학습 모델

## Azure Machine Learning 기능
- 중앙 집중식 데이터 세트 관리
- 주문형 컴퓨팅 리소스
- **AutoML**: 자동화된 기계 학습
- 시각적 파이프라인 도구
- MLflow 통합
- 책임 있는 AI 메트릭

## 모델 배포
- **실시간 예측**: 들어오는 새 데이터 즉시 채점
- **일괄 예측**: 새 데이터 일괄 채점 및 파일/데이터베이스 저장
- **컴퓨팅 옵션**: ACI, AKS, 컴퓨팅 클러스터
