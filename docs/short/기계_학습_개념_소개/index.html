기계 학습 개념 소개 - 요약

개요​

기계 학습은 데이터 과학 및 소프트웨어 엔지니어링의 교차점입니다. 기계 학습의 목표는 데이터를 사용하여 소프트웨어 애플리케이션 또는 서비스에 통합할 수 있는 예측 모델을 만드는 것입니다. 기계 학습은 데이터의 통계 및 수학 모델링의 기원을 가지고 있으며, 과거 관찰의 데이터를 사용하여 알 수 없는 결과 또는 값을 예측합니다.

핵심 개념​

기계 학습의 기본 원리​

기계 학습 모델은 하나 이상의 입력 값을 기반으로 출력 값을 계산하는 함수를 캡슐화하는 소프트웨어 애플리케이션입니다. 수학적으로 표현하면:

y = f(x)

여기서:

  • x (기능/특징): 관찰되는 항목의 관찰된 특성 (예: 온도, 체중, 지느러미 길이)
  • y (레이블): 예측하도록 모델을 학습하려는 항목의 알려진 값 (예: 아이스크림 판매 수, 당뇨병 위험, 펭귄 종)
  • f (함수): 기능 값을 사용하여 레이블을 계산하는 함수

학습과 추론​

  • 학습: 알고리즘을 사용하여 기능과 레이블 간의 관계를 확인하고, y를 계산하기 위해 x에서 수행할 수 있는 계산으로 해당 관계를 일반화하는 프로세스
  • 추론: 학습된 모델을 사용하여 새 데이터 값에 대한 예측을 생성하는 프로세스
  • 예측값 (ŷ): 모델의 출력은 관찰된 값이 아니라 함수에 의해 계산된 예측이므로 "y-hat"으로 표시

기계 학습 유형​

1. 감독된 기계 학습​

학습 데이터에 기능 값과 알려진 레이블 값이 모두 포함된 기계 학습 알고리즘입니다. 과거 관찰에서 기능과 레이블 간의 관계를 결정하여 모델을 학습시키므로 향후 사례에서 알 수 없는 레이블을 기능에 대해 예측할 수 있습니다.

회귀​

모델에서 예측하는 레이블이 숫자 값인 감독된 기계 학습의 한 형태입니다.

예시:

  • 온도, 강우량 및 윈드스피드에 따라 지정된 날에 판매되는 아이스크림의 수
  • 부동산의 판매 가격 (크기, 침실 수, 위치에 따라)
  • 자동차의 연료 효율 (엔진 크기, 무게, 치수에 따라)

학습 프로세스:

  1. 데이터를 학습 세트와 검증 세트로 분할
  2. 선형 회귀와 같은 회귀 알고리즘을 사용하여 학습 데이터에 모델 맞추기
  3. 검증 데이터를 사용하여 모델 테스트
  4. 예측된 레이블과 실제 레이블 비교하여 평가 메트릭 계산

분류​

레이블이 분류 또는 클래스를 나타내는 감독된 기계 학습의 한 형태입니다.

이진 분류:

  • 두 가지 상호 배타적 결과 중 하나를 예측
  • 예시: 환자가 당뇨병 위험에 처해 있는지 여부, 은행 고객이 대출을 상환하지 못할 가능성

다중 클래스 분류:

  • 여러 가능한 클래스 중 하나를 나타내는 레이블 예측
  • 예시: 펭귄의 종 (아델리, 젠투, 친스트랩), 영화의 장르

학습 프로세스:

  1. 학습 데이터를 클래스 레이블이 true일 확률을 계산하는 함수에 맞추기
  2. 로지스틱 회귀와 같은 알고리즘 사용 (0.0에서 1.0 사이의 확률 값 생성)
  3. 임계값(일반적으로 0.5)을 사용하여 true/false 예측
  4. 혼동 행렬을 사용하여 모델 평가

2. 감독되지 않은 기계 학습​

알려진 레이블이 없는 기능 값으로만 구성된 데이터를 사용하는 학습 모델입니다. 학습 데이터에서 관찰 기능 간의 관계를 결정합니다.

클러스터링​

해당 기능을 기반으로 관찰 간의 유사성을 식별하고 개별 클러스터로 그룹화합니다.

예시:

  • 크기, 잎 수 및 꽃잎 수에 따라 비슷한 꽃을 그룹화
  • 인구 통계 특성 및 구매 동작에 따라 유사한 고객 그룹 식별

K-평균 클러스터링 프로세스:

  1. 기능 값을 n차원 좌표로 벡터화
  2. 클러스터 수 k 결정 및 임의 좌표로 중심점 그리기
  3. 각 데이터 지점을 가장 가까운 중심에 할당
  4. 각 중심을 해당 데이터 요소의 가운데로 이동
  5. 중심 이동 및 클러스터 재할당을 반복하여 안정화

클러스터링과 분류의 차이:

  • 분류: 학습 데이터의 관찰이 속한 클래스를 이미 알고 있음
  • 클러스터링: 이전에 알려진 클러스터 레이블이 없으며 알고리즘은 기능의 유사성에 따라 데이터 관찰을 그룹화

회귀 평가 메트릭​

MAE (평균 절대 오차)​

예측과 실제 값 간의 평균 절대 차이입니다. 각 예측에서 잘못된 값을 나타내며, 예측이 실제 값보다 높거나 낮았는지 여부는 중요하지 않습니다.

계산: 절대 오차의 평균

MSE (평균 제곱 오차)​

제곱 오차의 평균입니다. 더 큰 오차를 "증폭"하여 소량으로 일관되게 잘못된 오류를 만드는 모델보다 더 적지만 더 큰 오류를 만드는 모델을 선호합니다.

계산: 개별 오차를 제곱하고 제곱 값의 평균 계산

RMSE (평균 제곱 오차)​

MSE의 제곱근입니다. 오차 값을 제곱하기 때문에 결과 지표는 더 이상 레이블로 측정된 수량을 나타내지 않으므로, MSE의 제곱근을 계산하여 원래 단위로 오차를 측정합니다.

계산: √MSE

R² (결정 계수)​

모델이 설명할 수 있는 검증 결과의 분산 비율을 측정하는 메트릭입니다. 0에서 1 사이의 값으로, 1에 가까울수록 모델이 검증 데이터에 더 적합합니다.

계산: R² = 1 - ∑(y-ŷ)² ÷ ∑(y-ȳ)²

분류 평가 메트릭​

혼동 행렬​

가능한 각 클래스 레이블에 대한 정확하고 잘못된 예측 수의 행렬입니다.

  • 진양성 (TP): ŷ=1 및 y=1
  • 진음성 (TN): ŷ=0 및 y=0
  • 가양성 (FP): ŷ=1 및 y=0
  • 가음성 (FN): ŷ=0 및 y=1

정확도​

모델이 올바르게 얻은 예측의 비율입니다.

계산: (TN+TP) ÷ (TN+FN+FP+TP)

제한사항: 항상 0을 예측하는 모델도 높은 정확도를 달성할 수 있으므로, 정확도만으로는 모델의 성능을 완전히 평가하기 어렵습니다.

재현율 (Recall)​

모델이 올바르게 식별한 긍정 사례의 비율입니다. 즉, 실제 긍정 사례 중 모델이 얼마나 많은 것을 올바르게 식별했는지를 측정합니다.

계산: TP ÷ (TP+FN)

정밀도 (Precision)​

실제 레이블이 실제로 양수인 예측 긍정 사례의 비율입니다. 즉, 모델에 의해 긍정으로 예측된 사례 중 실제로 긍정인 비율을 측정합니다.

계산: TP ÷ (TP+FP)

F1 점수​

재현율과 정밀도를 결합한 전체 메트릭입니다.

계산: (2 × 정밀도 × 재현율) ÷ (정밀도 + 재현율)

AUC (곡선 아래 영역)​

ROC (수신자 조작 특성) 곡선 아래의 영역입니다. 0.0에서 1.0 사이의 가능한 모든 임계값에 대해 TPR (진양성 비율) 및 FPR (가양성 비율)을 비교합니다.

  • 완벽한 모델: AUC = 1.0
  • 무작위 추측: AUC = 0.5
  • AUC가 0.5보다 높으면 무작위 추측보다 더 나은 성능

딥 러닝​

인공 신경망​

수학적 기능을 사용하여 생물학적 뉴런에서 전기 화학 활동을 시뮬레이션합니다. 여러 층의 뉴런으로 구성되며, 본질적으로 심층적으로 중첩된 기능을 정의합니다.

구성 요소:

  • 입력 계층: 기능 데이터(x)를 받는 뉴런
  • 은닉 계층: 가중치(w)를 적용하여 중간 계산 수행
  • 출력 계층: 예측 값 생성 (분류의 경우 확률 분포)

신경망 학습 프로세스​

  1. 학습 데이터 입력: 학습 및 검증 데이터 세트 정의, 학습 기능을 입력 계층에 공급
  2. 순전파: 네트워크의 각 계층에 있는 뉴런이 가중치를 적용하고 네트워크를 통해 데이터 공급
  3. 출력 생성: 출력 계층이 계산된 값을 포함하는 벡터 생성 (예: [0.3, 0.1, 0.6])
  4. 손실 계산: 손실 함수가 예측된 값을 알려진 y 값과 비교하고 차이를 집계
  5. 역전파: 최적화 함수가 차등 미적분을 사용하여 손실에 대한 각 가중치의 영향을 평가하고 조정
  6. 반복: 손실이 최소화되고 모델이 허용 가능한 정확도로 예측할 때까지 여러 epoch를 통해 반복

손실 함수​

예측된 레이블 값과 실제 레이블 값의 차이를 정량화합니다. 손실을 줄이기 위해 가중치를 조정하는 것이 학습의 목표입니다.

학습 프로세스의 반복적 특성​

기계 학습 모델을 학습하는 것은 종종 반복적인 프로세스로, 각 단계를 여러 번 반복하여 가장 성능이 좋은 모델을 찾습니다:

  • 기능 선택 및 준비: 모델에 포함할 기능 선택 및 더 나은 적합성을 보장하기 위한 계산 적용
  • 알고리즘 선택: 다양한 알고리즘 시도 (선형 회귀, 로지스틱 회귀, 신경망 등)
  • 하이퍼 매개 변수 조정: 알고리즘 동작을 제어하기 위한 숫자 설정 조정
  • 평가 및 개선: 허용되는 평가 메트릭이 달성될 때까지 반복
