# 생성형 AI 및 Agent 소개 - 요약

## LLM (대규모 언어 모델)
- **정의**: 어휘 내 단어와 구 간의 언어적 및 의미적 관계를 캡슐화
- **기능**: 자연어 입력을 추론하고 의미 있는 응답 생성

## 토큰화
- **토큰**: 단어, 하위 단어, 문장 부호 등
- **프로세스**: 학습 텍스트를 고유 토큰으로 분해하고 정수 식별자 할당

## 변환기 모델
- **인코더 블록**: 주의 기술로 임베딩 생성
  - 다중 헤드 주의: 토큰의 여러 요소 병렬 평가
  - 완전히 연결된 신경망: 최적 벡터 표현 찾기
- **디코더 블록**: 포함을 사용하여 다음 토큰 예측
  - 마스킹된 주의: 앞에 오는 토큰만 컨텍스트에 포함

## 임베딩
- **정의**: 토큰의 언어 및 의미 체계 특성을 포함한 벡터 표현
- **특징**: 유사한 컨텍스트에서 사용되는 토큰은 비슷한 방향의 벡터 생성
- **코사인 유사성**: 토큰 간 의미 체계적 거리 측정

## 프롬프트 기반 완성
- **프롬프트**: LLM에 제공하는 입력 (질문, 명령, 대화 시작)
- **프롬프트 유형**:
  - **시스템 프롬프트**: 모델의 동작과 톤 설정
  - **사용자 프롬프트**: 특정 질문이나 명령

## 대화 내용
- **컨텍스트 유지**: 대화 기록 추적 및 요약 버전 포함
- **RAG (검색 증강 생성)**: 문서 검색하여 프롬프트 보강

## 프롬프트 작성 팁
- 명확하고 구체적
- 컨텍스트 추가
- 예제 사용
- 구조 요청 (글머리 기호, 테이블 등)

## AI 에이전트
- **정의**: 자연어를 추론 및 생성하고, 도구를 사용하여 작업 자동화하는 소프트웨어

## AI 에이전트 구성 요소
1. **큰 언어 모델**: 언어 이해 및 추론
2. **지침**: 시스템 프롬프트로 역할 및 동작 정의
3. **도구**: 정보 액세스 및 작업 수행 도구

## 다중 에이전트 시스템
- **협업**: 여러 에이전트가 각각 고유한 전문 분야로 공동 작업
- **워크플로**: 데이터 수집, 분석, 조치 등 복잡한 워크플로 처리
