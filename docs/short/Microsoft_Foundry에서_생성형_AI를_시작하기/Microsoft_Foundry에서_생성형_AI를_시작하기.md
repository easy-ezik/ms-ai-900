# Microsoft Foundry에서 생성형 AI를 시작하기 - 요약

## 개요
생성형 AI는 새로운 콘텐츠를 만드는 데 중점을 둔 인공 지능의 하위 집합으로, 작업 방식을 바꾸고 기술로 가능한 것에 혁명을 일으켰습니다. Microsoft는 AI 사용 및 개발을 위한 도구 에코시스템을 제공하며, 이 모듈에서는 Microsoft Foundry를 중심으로 생성 AI 애플리케이션을 빌드하는 방법을 살펴봅니다.

## 핵심 개념

### 생성형 AI 애플리케이션
생성 AI 애플리케이션은 언어 모델을 사용하여 빌드됩니다. 이러한 언어 모델은 사용자와 생성 AI 간의 상호 작용의 '앱 논리' 구성 요소를 지원합니다.

### 도우미 (Assistant)
생성형 AI는 종종 사용자가 정보를 찾고 효율적으로 작업을 수행하는 데 도움이 되는 애플리케이션에 통합된 채팅 기반 도우미로 나타납니다. 

**예시: Microsoft Copilot**
- 실시간 인텔리전스와 지원을 제공하여 업무 경험을 향상시키는 AI 기반 생산성 도구
- 비즈니스 사용자는 AI 생성 콘텐츠 및 작업 자동화를 통해 생산성과 창의성 향상
- 개발자는 Copilot를 비즈니스 프로세스 및 데이터에 통합하는 플러그 인을 만들거나, 앱 및 서비스에 생성 AI 기능을 빌드하는 에이전트를 만들 수 있음

### 에이전트 (Agent)
몇 가지 예로 세금 신고 또는 배송 준비 조정과 같은 작업을 실행할 수 있는 생성 AI를 에이전트라고 합니다. 에이전트는 사용자 입력에 응답하거나 상황을 자율적으로 평가하고 적절한 조치를 취할 수 있는 애플리케이션입니다.

**에이전트의 세 가지 주요 구성 요소:**
1. **언어 모델**: 추론 및 언어 이해를 지원
2. **지침**: 에이전트의 목표, 동작 및 제약 조건을 정의
3. **도구 또는 함수**: 에이전트가 작업을 완료할 수 있도록 함

**예시:** "임원 도우미" 에이전트는 사용자의 일정에 있는 모임 장소에 대한 세부 정보를 제공한 다음, 맵을 첨부하거나 택시나 승차 공유 서비스 예약을 자동화할 수 있습니다.

### 오케스트레이션
통합 솔루션에서 효율적으로 함께 작동하도록 모델, 데이터 원본, 도구 및 워크플로와 같은 여러 AI 구성 요소를 조정하고 관리하는 프로세스입니다.

## 생성 AI 애플리케이션 분류

생성형 AI 애플리케이션을 세 개의 버킷으로 분류할 수 있습니다:

### 1. 즉시 사용
- 프로그래밍 작업 없이 즉시 사용할 수 있는 생성 AI 애플리케이션
- 간단히 도우미에게 질문을 하는 것부터 시작

### 2. 확장 가능
- 일부 즉시 사용할 수 있는 애플리케이션은 사용자 고유의 데이터를 사용하여 확장 가능
- 사용자 지정을 통해 도우미는 특정 비즈니스 프로세스나 작업을 더 잘 지원
- **예시**: Microsoft Copilot은 즉시 사용 가능하고 확장 가능한 기술

### 3. 기초에서 빌드하는 애플리케이션
- 언어 모델부터 시작하여 에이전트 기능이 있는 도우미와 자체 도우미를 직접 빌드
- Microsoft Foundry와 같은 서비스를 사용하여 생성 AI 애플리케이션을 확장하거나 빌드

## Microsoft Foundry 개요

Microsoft Foundry는 엔터프라이즈 AI 운영, 모델 작성기 및 애플리케이션 개발을 위한 Microsoft의 통합 플랫폼입니다. PaaS(Platform as a Service)로, 개발자에게 애플리케이션 빌드에 사용되는 언어 모델의 사용자 지정을 제어할 수 있습니다.

### Foundry 구성 요소

#### 1. Microsoft Foundry 모델 카탈로그
- 생성 AI 개발을 위한 다양한 모델을 검색, 비교 및 배포하기 위한 중앙 집중식 허브
- Microsoft에서 직접 판매하는 모델과 파트너 및 커뮤니티의 모델 포함
- Foundry 모델의 Azure OpenAI는 Microsoft의 자사 모델 제품군을 구성하며 기본 모델로 간정
- 모델 순위표(미리 보기)를 활용하여 품질, 비용 및 처리량과 같은 다양한 기준에서 가장 잘 수행되는 모델 확인

#### 2. 운동장 (Playground)
- 아이디어를 빠르게 테스트하고, 모델을 사용해 보고, Foundry 모델을 탐색할 수 있는 즉시 사용할 수 있는 환경
- 플레이그라운드 설정에서 다양한 모델을 테스트 가능

#### 3. 주조 도구 (Foundry Tools)
- Microsoft Foundry에서 Foundry 도구를 빌드, 테스트, 데모 참조 및 배포
- Azure Speech, Azure Language, Azure Vision 및 Microsoft Foundry Content Safety 등 모든 종류의 Foundry 도구 테스트

#### 4. 솔루션 (Solutions)
- Microsoft Foundry에서 에이전트를 빌드하고 모델을 사용자 지정

#### 5. 관찰 가능성 (Observability)
- 애플리케이션 모델의 사용량 및 성능을 모니터링하는 기능

### Foundry 기능 이해

Microsoft Foundry는 허브 및 프로젝트를 기반으로 하는 사용자 인터페이스를 제공합니다:

- **허브**: Azure AI 및 Azure Machine Learning에 대한 보다 포괄적인 액세스 권한 제공
- **프로젝트**: 모델 및 에이전트 개발에 대한 보다 구체적인 액세스 제공
- Azure AI Hub를 만들 때 Foundry Tools 리소스를 포함하여 여러 다른 리소스가 함께 만들어짐

## 모델 사용자 지정 방법

생성 AI 애플리케이션에서 모델을 사용자 지정하는 목적은 응답의 품질 및 안전을 포함하여 성능의 측면을 개선하는 것입니다.

### 1. 접지 데이터 사용
접지란 시스템의 출력이 사실, 상황별 또는 신뢰할 수 있는 데이터 원본과 정렬되도록 하는 프로세스입니다. 

**접지 작업 방법:**
- 모델을 데이터베이스에 연결
- 검색 엔진을 사용하여 실시간 정보를 검색
- 도메인별 기술 자료를 통합

**목표**: 모델의 응답을 이러한 데이터 원본에 고정하여 생성된 콘텐츠의 신뢰성과 적용 가능성을 향상

### 2. RAG (검색 증강 생성) 구현
RAG는 조직의 전용 데이터베이스에 연결하여 언어 모델을 보강합니다.

**프로세스:**
- 큐레이팅된 데이터 세트에서 관련 정보를 검색
- 검색된 정보를 사용하여 상황에 맞는 정확한 응답 생성

**장점:**
- 최신 및 도메인 관련 정보를 제공하여 모델의 성능 향상
- 보다 정확하고 관련 있는 답변 생성

**사용 사례**: 고객 지원 또는 지식 관리 시스템과 같은 동적 데이터에 대한 실시간 액세스가 중요한 애플리케이션

### 3. 미세 조정 (Fine-tuning)
미리 학습된 모델을 사용하고 특정 애플리케이션에 더 적합하도록 더 작은 작업별 데이터 세트에 대해 추가로 학습하는 작업입니다.

**프로세스:**
- 미리 학습된 모델 사용
- 작업별 데이터 세트에 대해 추가 학습

**장점:**
- 모델이 전문화되어 도메인별 지식이 필요한 특정 작업을 더 잘 수행
- 모델을 도메인별 요구 사항에 맞게 조정
- 정확도 향상 및 관련이 없거나 부정확한 응답 생성 가능성 감소

### 4. 보안 및 거버넌스 제어 관리
액세스, 인증 및 데이터 사용을 관리하려면 보안 및 거버넌스 제어가 필요합니다. 이러한 제어 기능은 올바르지 않거나 권한이 없는 정보의 게시를 방지하는 데 도움이 됩니다.

## 관찰 가능성 (Observability)

생성 AI의 응답 품질을 측정하는 방법에는 여러 가지가 있습니다. 일반적으로 생성형 AI를 평가하고 모니터링하기 위한 세 가지 차원이 있습니다:

### 1. 성능 및 품질 평가자
생성된 콘텐츠의 정확도, 근거 및 관련성을 평가합니다.

**평가 항목:**
- **근거 (Groundedness)**: 검색된 컨텍스트와 관련하여 응답이 얼마나 일관된지 측정
- **관련성 (Relevance)**: 쿼리와 관련하여 응답이 얼마나 관련성이 있는지 측정
- **유창성 (Fluency)**: 자연어 품질과 가독성을 측정
- **일관성 (Coherence)**: 논리적 일관성 및 응답 흐름을 측정

### 2. 위험 및 안전 평가자
AI 생성 콘텐츠와 관련된 잠재적 위험을 평가하여 콘텐츠 위험으로부터 보호합니다.

**평가 항목:**
- **콘텐츠 안전**: 다양한 안전 문제에 대한 포괄적인 평가
- 유해하거나 부적절한 콘텐츠를 생성하는 AI 시스템의 경향 평가

### 3. 사용자 지정 평가자
특정 요구 사항 및 목표를 충족하는 산업별 메트릭입니다.

## Copilot Studio

Microsoft의 Copilot Studio는 또 다른 생성 AI 개발 도구입니다:

- 기술적으로 능숙한 비즈니스 사용자 또는 개발자가 대화형 AI 환경을 만들 수 있는 로우 코드 개발 시나리오에 적합
- 결과 에이전트는 Microsoft 365 환경에서 호스트되고 Microsoft Teams와 같은 채팅 채널을 통해 제공되는 완전히 관리되는 SaaS(서비스로서의 소프트웨어) 솔루션
- 인프라 고려 사항 및 모델 배포 세부 정보가 관리되므로 효과적인 솔루션을 만드는 데 쉽게 집중 가능

## 사용 사례 예시

### 마케팅 콘텐츠 만들기
회사는 Microsoft Copilot의 생성 AI를 사용하여 제품 설명, 블로그 게시물 및 소셜 미디어 콘텐츠를 자동으로 작성하여 시간을 절약하고 플랫폼 간에 브랜드 일관성을 보장합니다.

### 고객 지원
기업은 자연어로 고객 문의를 이해하고 응답할 수 있는 AI 기반 가상 에이전트를 배포하여 24/7 지원을 제공하고 인간 에이전트의 부하를 줄입니다.

### 코드 생성
개발자는 GitHub Copilot와 같은 도구를 사용하여 코드 조각을 생성하고, 함수를 제안하고, 자연어 프롬프트에 따라 전체 모듈을 작성하여 소프트웨어 개발 속도를 향상합니다.

### 이미지 및 비디오 생성
디자이너 및 콘텐츠 작성자는 Microsoft Foundry의 모델 카탈로그에 있는 최신 모델을 사용하여 종종 텍스트 설명에서 캠페인, 스토리보드 또는 개념 아트에 대한 시각적 개체를 생성합니다.

### 맞춤형 학습 및 튜터링
교육 플랫폼은 생성 AI를 사용하여 학생의 학습 스타일 및 진행 상황에 맞는 사용자 지정 퀴즈, 설명 및 학습 가이드를 만듭니다.
