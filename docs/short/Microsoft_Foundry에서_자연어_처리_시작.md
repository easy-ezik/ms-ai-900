# Microsoft Foundry에서 자연어 처리 시작 - 요약

## 개요
NLP(자연어 처리)는 기계가 인간의 언어를 이해하고 해석하고 응답할 수 있도록 하는 데 초점을 맞춘 인공 지능 분야입니다. NLP의 목표는 기존 텍스트에서 의미 또는 구조를 분석하고 추출하는 것입니다.

## NLP 애플리케이션 예시

### 고객 피드백 분석
조직은 대량의 고객 리뷰, 지원 티켓 또는 설문 조사 응답을 분석해야 합니다. 기업은 감정 분석 및 핵심 구 추출을 적용하여 추세를 식별하고, 불만을 조기에 감지하고, 고객 환경을 개선할 수 있습니다.

### 의료 텍스트 분석
의료 부문에서 Azure의 언어 솔루션은 구조화되지 않은 의료 문서에서 임상 정보를 추출하는 데 사용됩니다. 건강을 위한 엔터티 인식 및 텍스트 분석과 같은 기능은 증상, 약물 및 진단을 식별하여 더 빠르고 정확한 의사 결정을 지원합니다.

### 가상 에이전트를 사용한 대화형 AI
Azure의 언어 솔루션은 사용자 의도를 해석하고, 대화를 번역하고, 관련 엔터티를 추출하고, 적절하게 응답할 수 있는 가상 도우미를 지원합니다.

## Azure NLP 서비스

### Azure Language 서비스
텍스트를 이해하고 분석하는 기능을 포함하는 클라우드 기반 서비스입니다. Azure Language는 구조화되지 않은 텍스트에 대해 고급 자연어 처리를 수행할 수 있는 Foundry Tools 제품의 일부입니다.

### Azure Translator 서비스
텍스트의 의미 체계 컨텍스트를 분석하고 결과적으로 보다 정확하고 완전한 번역을 렌더링하는 번역에 NMT(신경망 기계 번역)를 사용하는 클라우드 기반 서비스입니다.

## Azure Language 텍스트 분석 기능

### 1. 명명된 엔터티 인식
사람, 장소, 이벤트 등을 식별합니다. 사용자 지정 범주를 추출하도록 이 기능을 사용자 지정할 수도 있습니다.

**인식 가능한 엔터티 유형:**
- **사람**: "Bill Gates", "John"
- **위치**: "Paris", "New York"
- **조직**: "Microsoft"
- **수량**: 숫자, 백분율, 서수, 나이, 통화, 차원, 온도
- **날짜와 시간**: 날짜, 시간, 날짜 범위, 시간 범위, 기간, 설정
- **URL**: https://www.bing.com
- **전자 메일**: support@microsoft.com
- **전화 번호**: "(312) 555-0176"
- **IP 주소**: "10.0.1.125"

**예시:** "지난 주에 시애틀에 있는 레스토랑에서 먹었어요."
- 시애틀 → 위치 (Wikipedia URL 제공)
- 지난주 → 날짜와 시간 (날짜 범위)

### 2. 엔터티 링크
Wikipedia에 대한 링크와 함께 알려진 엔터티를 식별합니다. 특정 참조에 연결함으로써 엔터티를 명확하게 구분하는 데 도움을 줍니다.

### 3. PII(개인 식별 정보) 검색
개인 건강 정보(PHI)를 포함하여 개인적으로 중요한 정보를 식별합니다.

### 4. 언어 감지
텍스트를 쓰는 언어를 식별하고 다음을 반환합니다:
- 언어 이름 (예: "영어")
- ISO 6391 언어 코드 (예: "en")
- 언어 감지에 대한 신뢰도 수준을 나타내는 점수

**예시:**
- "A fantastic place for lunch. The soup was delicious." → 영어 (en), 점수 1.0
- "Comida maravillosa y gran servicio." → 스페인어 (es), 점수 1.0
- "The croque monsieur avec frites was terrific. Bon appetit!" → 영어 (en), 점수 0.9 (혼합 언어)

**참고:** 언어 감지 서비스는 텍스트의 주요 언어에 중점을 둡니다. 혼합 언어 텍스트의 경우 신뢰도 점수가 1보다 작을 수 있습니다.

### 5. 감정 분석 및 오피니언 마이닝
텍스트가 긍정인지 부정적인지 여부를 식별합니다. 소셜 미디어, 고객 리뷰, 토론 포럼 등에서 긍정적이고 부정적인 감정을 감지하는 데 유용합니다.

**작동 방식:**
- 미리 빌드된 기계 학습 분류 모델 사용
- 긍정, 중립 및 부정의 세 가지 범주로 감정 점수 반환
- 각 범주에서 0에서 1 사이의 점수 제공
- 하나의 문서 감정도 제공

**예시:**
- 긍정적 리뷰: 문서 감정 긍정, 긍정 점수 0.90, 중립 점수 0.10, 부정 점수 0.00
- 부정적 리뷰: 문서 감정 부정, 긍정 점수 0.00, 중립 점수 0.00, 부정 점수 0.99

### 6. 요약
가장 중요한 정보를 식별하여 텍스트를 요약합니다.

### 7. 핵심 구 추출
구조화되지 않은 텍스트의 주요 개념을 나열합니다. 많은 리뷰를 읽는 데 시간이 오래 걸릴 수 있는 경우 주요 사항을 요약하는 데 유용합니다.

**예시:** 레스토랑 리뷰에서 다음 핵심 구 추출:
- 생일 축하
- 환상적인 경험
- 친절한 안주인
- 훌륭한 음식
- 세심한 서비스

## Azure Language 대화형 AI 기능

### 질문 답변
자동화된 대화 요소가 필요한 자연어 AI 워크로드를 지원합니다. 일반적으로 질문 답변은 고객 쿼리에 응답하는 봇 애플리케이션을 빌드하는 데 사용됩니다.

**특징:**
- 즉시 응답
- 문제를 정확하게 답변
- 자연스러운 다중 전환 방식으로 사용자와 상호 작용
- 웹 사이트 또는 소셜 미디어 플랫폼과 같은 다양한 플랫폼에서 구현 가능

**사용 방법:**
- Azure Language 서비스를 사용하여 자연어 입력을 사용하여 쿼리할 수 있는 질문 및 답변 쌍의 기술 자료 생성
- 사용자 지정 질문 답변 기능 포함

### 대화형 언어 이해 (CLU)
대화형 설정에서 구의 의미를 해석하는 언어 모델을 빌드할 수 있습니다. 엔드투엔드 대화형 애플리케이션을 빌드하는 데 사용할 수 있는 기능 집합을 설명합니다.

**특징:**
- 자연어 이해 모델을 사용자 지정하여 들어오는 구의 전반적인 의도를 예측
- 중요한 정보 추출

**사용 사례:**
- 명령 및 제어: "조명 끄기"와 같은 오디오 입력을 사용하고 조명을 끄는 것과 같이 수행해야 하는 작업을 이해
- 엔드투엔드 대화
- 엔터프라이즈 지원

**참고:** 최신 AI 솔루션에서는 여러 AI 기능이 서로 함께 작동하거나, 진화하거나, 서로 구축되는 경우가 많습니다. 이러한 대화형 AI 기능은 생성 AI 기능과 유사할 수 있습니다. 생성 AI는 NLP를 기초로 사용하지만 새 콘텐츠를 만들어 그 이상으로 확장합니다.

## Azure Translator 기능

### 기계 번역의 발전
기계 번역의 초기 시도는 리터럴 번역을 적용했습니다. 직역은 각 단어가 대상 언어의 해당 단어로 번역되는 것이지만, 이 방법에는 몇 가지 문제가 있습니다:
- 대상 언어에 동등한 단어가 없을 수 있음
- 직역이 문장의 의미를 변경하거나 내용을 부정확하게 전달할 수 있음

Azure Translator는 단어뿐만 아니라 사용되는 의미 체계 컨텍스트도 이해할 수 있어 입력 구문 또는 문장을 보다 정확하게 번역할 수 있습니다.

### Azure Translator 기능

#### 텍스트 번역
130개 이상의 언어 간에 텍스트 텍스트 변환을 지원합니다. 하나의 언어를 원본 언어로 지정하고 여러 타겟 언어로 지정하여 원본 문서를 동시에 여러 언어로 번역할 수 있습니다.

**특징:**
- 실시간으로 빠르고 정확한 텍스트 번역
- 지원되는 모든 언어에서 사용 가능

#### 문서 번역
원본 문서 구조를 유지하면서 지원되는 모든 언어에서 여러 문서를 번역하는 데 사용됩니다.

#### 사용자 지정 번역
엔터프라이즈, 앱 개발자 및 언어 서비스 공급자가 사용자 지정된 NMT(신경망 기계 번역) 시스템을 빌드할 수 있도록 합니다.

### Microsoft Translator Pro
원활한 실시간 음성 음성 변환을 가능하게 하는 엔터프라이즈용으로 특별히 설계된 모바일 애플리케이션입니다.

## Microsoft Foundry 시작

### 리소스 유형
애플리케이션에서 Azure Language 또는 Azure Translator를 사용하려면 Azure 구독에 적절한 리소스를 프로비전해야 합니다.

**선택 가능한 리소스:**
1. **언어 리소스**: Azure 언어 서비스만 사용하려는 경우 또는 리소스에 대한 액세스 및 청구를 다른 서비스와 별도로 관리하려는 경우
2. **Translator 리소스**: 각 서비스에 대한 액세스 및 청구를 개별적으로 관리할지 선택
3. **Foundry 도구 리소스**: 다른 Foundry 도구와 함께 Azure Language를 사용할 계획이며 이러한 서비스에 대한 액세스 및 청구를 함께 관리할 것인지 선택

### Microsoft Foundry 포털
Microsoft Foundry는 엔터프라이즈 AI 운영, 모델 작성기 및 애플리케이션 개발을 위한 통합 플랫폼을 제공합니다.

**구조:**
- **허브 및 프로젝트 기반**: 사용자 인터페이스 제공
- **프로젝트 생성**: Microsoft Foundry에서 프로젝트를 만들면 Foundry Tools 리소스도 자동 생성
- **프로젝트의 역할**: 작업 및 리소스를 효과적으로 조직하는 데 도움, 데이터 세트, 모델 및 기타 리소스에 대한 컨테이너 역할

**플레이그라운드:**
- 언어 놀이터: Azure Language 기능 테스트
- 번역기 놀이터: Azure Translator 기능 테스트
- 샘플 텍스트로 서비스 기능 사용해 보기

### 리소스 생성 방법
- Azure Portal과 Microsoft Foundry 포털 모두 리소스를 만들기 위한 사용자 인터페이스 제공
- 사용자 인터페이스를 사용하여 리소스를 만들거나 스크립트를 작성할 수 있음
- 실행 중인 Foundry 도구의 예제를 보려면 Microsoft Foundry 포털 선택
