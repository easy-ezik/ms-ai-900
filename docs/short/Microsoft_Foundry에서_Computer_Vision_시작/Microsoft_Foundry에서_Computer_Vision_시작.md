# Microsoft Foundry에서 Computer Vision 시작 - 요약

## 핵심 개념
- **Computer Vision**: 컴퓨터가 이미지, 비디오, 라이브 카메라 피드를 해석하고 이해하는 AI 분야
- **Azure Vision**: 딥 러닝 기반 미리 빌드된 컴퓨터 비전 모델 제공

## Azure Vision 서비스 구성
1. **Azure Vision Image Analysis Service**
   - 일반적인 개체 검색
   - 시각적 기능 태그 지정
   - 캡션 생성
   - OCR (광학 문자 인식)

2. **Azure AI Face 서비스**
   - 얼굴 감지, 인식, 분석
   - 얼굴 특성 추출

## 이미지 분석 기능
- **캡션이 있는 이미지 설명**: 사람이 읽을 수 있는 설명 생성
- **일반적인 개체 검색**: 수천 개 공통 개체 식별 (경계 상자 좌표 포함)
- **시각적 기능 태그 지정**: 내용에 따른 태그 제안
- **OCR**: 이미지에서 텍스트 추출

## 사용자 지정 모델
- **이미지 분류**: 이미지의 범주 또는 클래스 예측
- **객체 탐지**: 이미지에서 개체 검색 및 분류

## Azure AI Face 서비스 기능
- **얼굴 감지**: 얼굴 위치 식별 (경계 상자 좌표)
- **얼굴 인식**: 알려진 개인 식별
- **얼굴 특성**: 액세서리, 흐림, 노출, 안경, 머리 자세, 마스크, 노이즈, 가림, 인식 품질

## 책임 있는 AI
- 제한된 액세스 정책 적용
- 얼굴 검증, 식별, 라이브니스 탐지는 접수 양식 제출 필요

## Microsoft Foundry 시작
- **리소스 유형**: Azure Vision 리소스 또는 Foundry 도구 리소스
- **프로젝트 생성**: Foundry 도구 리소스 자동 생성
- **플레이그라운드**: 샘플 이미지로 기능 테스트
