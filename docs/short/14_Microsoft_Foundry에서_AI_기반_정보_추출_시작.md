# Microsoft Foundry에서 AI 기반 정보 추출 시작 - 요약

## 핵심 개념
- **정보 추출**: 문서, 이미지, 오디오에서 실행 가능한 인사이트 추출
- **OCR (광학 문자 인식)**: 이미지에서 텍스트 추출

## Azure AI 서비스
1. **Azure Vision 이미지 분석**
   - 자동화된 캡션 및 태그 생성
   - 객체 탐지
   - OCR

2. **Azure Content Understanding**
   - 양식 및 문서 분석 (스키마 기반 필드 추출)
   - 오디오 분석 (전사, 요약)
   - 이미지 및 비디오 분석

3. **Azure Document Intelligence**
   - 미리 빌드된 모델: 청구서, 영수증, 구매 주문 등
   - 사용자 지정 모델: 레이블이 지정된 예제로 학습

4. **Azure AI Search**
   - AI 기술 파이프라인으로 정보 추출 및 인덱싱
   - 지식 저장소에 추출된 데이터 유지

## 정보 추출 사용 사례
- **데이터 캡처**: 명함에서 연락처 정보 추출
- **비즈니스 프로세스 자동화**: 양식에서 데이터 읽고 워크플로 트리거
- **모임 요약 및 분석**: 녹음된 통화에서 핵심 요소 분석
- **DAM (디지털 자산 관리)**: 이미지/비디오에 자동 태그 지정 및 인덱싱
- **지식 마이닝**: 구조화/비구조화 데이터에서 키 정보 추출

## Azure AI Search 인덱서 프로세스
1. 원본에서 데이터 수집
2. 문서 해독하여 콘텐츠 추출
3. AI 기술 적용하여 필드 생성
4. 인덱스로 필드 유지
