소개

AI 기반 정보 추출 및 분석을 통해 조직은 문서, 이미지, 오디오 파일 또는 기타 자산에 잠겨 있을 수 있는 데이터에서 실행 가능한 인사이트를 얻을 수 있습니다.

정보 추출 시나리오의 예는 다음과 같습니다.

  • 회사는 직원 경비 청구를 처리해야 하며 스캔한 영수증에서 비용 설명 및 금액을 추출해야 합니다.
  • 고객 서비스 기관은 기록된 지원 호출을 분석하여 일반적인 문제 및 해결 방법을 식별하려고 합니다.
  • 역사 사회는 인구 조사 기록에서 데이터를 추출하고 스캔한 기록 문서에 저장해야 합니다.
  • 관광 단체는 인기 사이트에서 촬영한 비디오 영상과 이미지를 분석하여 방문자 볼륨을 예측하고 투어 용량 계획을 개선하는 데 도움을 주고자 합니다.
  • 대기업의 재무 부서는 중앙에서 받은 청구서를 적절한 부서에 지불하도록 라우팅하여 계정 지불 처리를 자동화하려고 합니다.
  • 마케팅 조직은 대량의 디지털 이미지와 문서를 분석하여 추출된 데이터를 추출하고 인덱싱하여 쉽게 검색하려고 합니다.

Azure AI에는 개별적으로 또는 함께 사용할 수 있는 여러 서비스가 포함되어 있으므로 이러한 종류의 정보 추출 시나리오를 지원합니다. 이 모듈에서는 이러한 서비스 및 해당 기능 중 일부를 살펴봅니다.

Azure AI 검색

Azure AI Search는 AI 기술 파이프라인을 사용하여 구조화되고 구조화되지 않은 콘텐츠에서 정보를 체계적으로 추출하고 인덱싱하는 AI 지원 인덱싱을 수행합니다.

이러한 각 서비스를 개별적으로 사용하거나 결합하여 다음을 위한 포괄적인 솔루션을 빌드할 수 있습니다.

  • 데이터 캡처: 지능적으로 이미지를 스캔하여 데이터 값을 캡처하고 저장합니다. 예를 들어 휴대폰 카메라를 사용하여 명함에서 연락처 정보를 추출합니다.
  • 비즈니스 프로세스 자동화: 양식에서 데이터를 읽고 이를 사용하여 워크플로를 트리거합니다. 예를 들어 청구서에서 비용 센터 및 청구 정보를 추출하고 처리를 위해 적절한 계정 지불 부서로 라우팅합니다.
  • 모임 요약 및 분석: 녹음된 전화 통화 또는 화상 회의 통화에서 핵심 요소를 분석하고 요약합니다. 예를 들어 팀 모임에 대한 메모 작성 및 작업 할당을 자동화합니다.
  • DAM(디지털 자산 관리) : 이미지 또는 비디오와 같은 디지털 자산에 자동으로 태그를 지정하고 인덱싱하여 관리합니다. 예를 들어 스톡 사진의 검색 가능한 라이브러리를 만듭니다.
  • 지식 마이닝: 추가 분석 및 보고에 사용할 구조화된 데이터와 구조화되지 않은 데이터에서 키 정보를 추출합니다. 예를 들어 검색된 레코드에서 인구 조사 데이터를 컴파일하여 데이터베이스를 채웁다.

OCR(광학 문자 인식)

이미지에 인쇄 또는 필기 텍스트가 포함된 경우 Azure Vision Image Analysis는 OCR( 광학 문자 인식 )이라는 기술을 사용하여 각 텍스트 줄 의 위치와 내용 및 각 개별 단어를 확인할 수 있습니다. Azure Vision Image Analysis의 OCR 기능은 추가 처리를 위해 이미지의 텍스트를 읽어야 하는 경우(예: 휴대폰 애플리케이션을 사용하여 메뉴를 번역하는 경우) 유용합니다. 텍스트 기반 문서 외에도 Azure Content Understanding은 오디오 파일을 분석하여 전사, 요약 및 기타 주요 인사이트를 제공할 수 있습니다.

AI가 음성 메일을 요약하도록 하려는 경우를 가정해 보겠습니다. 다음과 같이 기록된 각 호출에서 추출할 키 인사이트의 스키마를 정의할 수 있습니다.

  • 발신자
  • 메시지 요약
  • 요청된 작업
  • 콜백 번호
  • 대체 연락처 세부 정보

이제 발신자가 다음과 같은 음성 메시지를 남긴다고 가정합니다.

Hi, this is Ava from Contoso.

Just calling to follow up on our meeting last week.

  • 콜백 번호: 555-12345
  • 대체 연락처 세부 정보: Ava@contoso.com

이미지 및 비디오 분석

Azure Content Understanding은 사용자 지정 스키마를 기반으로 정보를 추출하는 이미지 및 비디오 분석을 지원합니다. 예를 들어 비디오 회의의 이미지를 분석하여 출석, 위치 및 기타 정보의 세부 정보를 추출할 수 있습니다.

회의실 내 참석자와 원격 참석자를 전화 회의 시스템에서 결합하는 공동 작업 메시징 시스템에서 찍은 이미지에 대해 다음 스키마를 정의했다고 가정합니다.

  • 위치
  • 직접 참석자
  • 원격 참석자
  • 총 참석자 수

Azure Content Understanding을 사용하여 회의실 카메라에서 다음 스틸 이미지를 분석할 수 있습니다.

이 이미지에 이전 스키마를 적용할 때 Azure Content Understanding은 다음 결과를 생성합니다.

  • 위치: 회의실
  • 대면 참석자: 1
  • 원격 참석자: 3
  • 총 참석자 수: 4

스틸 이미지를 분석하는 대신 통화의 녹화된 비디오에 대한 분석기를 만들어야 했습니다. 스키마에는 다양한 시간 간격으로 출석 횟수, 통화 중에 누가 말했는지, 말한 내용에 대한 세부 정보, 토론 요약 및 모임에서 할당된 작업 목록이 포함될 수 있습니다.

Azure Document Intelligence를 사용하여 양식에서 정보 추출

Azure Document Intelligence는 복잡한 문서 및 양식 처리 시나리오를 지원하도록 설계되었습니다. Azure Content Understanding을 사용하여 양식 및 문서에서 필드를 추출할 수도 있지만 Azure Document Intelligence는 간단한 영수증에서 복잡한 세금 양식에 이르기까지 미리 빌드된 모델의 큰 라이브러리를 제공합니다. 사용자 고유의 정교한 사용자 지정 모델을 만들 수도 있습니다.

Azure Document Intelligence를 사용하면 분석하려는 문서의 레이블이 지정된 예제를 사용하여 사용자 지정 모델을 학습시킬 수 있습니다. 문서에 레이블을 지정하려면 OCR을 사용하여 문서의 레이아웃 을 정의하고 추출하려는 문서의 불연속 필드를 식별해야 합니다.

Azure AI Search를 사용하여 지식 마이닝 솔루션 만들기

기본적으로 Azure AI Search는 데이터를 인덱싱하고 검색하기 위한 클라우드 서비스입니다. 그러나 AI 기술을 사용하여 여러 형식의 데이터에서 인사이트를 추출하고 Azure Vision 및 Azure Document Intelligence를 비롯한 다른 AI 서비스와 통합하는 기능을 통해 디지털 자산 관리 및 지식 마이닝 솔루션을 빌드하기 위한 강력한 플랫폼이 됩니다.

인덱서, 인덱스 및 기술

Azure AI Search 솔루션의 핵심은 반복 가능한 프로세스를 정의하는 인덱서입니다.

  1. 문서의 Azure Storage 컨테이너 또는 데이터베이스와 같은 원본에서 데이터를 수집합니다.
  2. 문서를 해독하여 콘텐츠를 추출합니다(예: PDF 문서에서 텍스트 및 이미지 데이터 검색).
  3. 일련의 작업을 적용하여 데이터에서 정보를 검색하고 인덱스에 대한 필드 계층 구조를 생성합니다. 일부 필드는 원본 데이터의 핵심 특성(예: 문서 파일 이름 및 마지막으로 저장된 날짜)이며, 다른 필드는 AI 기술을 사용하여 생성됩니다. 다음은 그 예입니다.
  • Azure Vision 서비스를 사용하여 이미지에 대한 태그 및 캡션을 생성합니다.
  • Azure Language 서비스를 사용하여 감정 또는 명명 엔티티에 대한 필드를 도출합니다.
  • Azure Document Intelligence를 사용하여 양식에서 필드 값을 추출합니다.
  1. 추출된 필드를 인덱스로 유지합니다.

결과 인덱스를 사용하여 사용자가 키워드 및 필터링 조건에 따라 추출된 필드에서 정보를 검색할 수 있습니다.

추출된 데이터를 지식 저장소에 유지

Azure AI Search는 검색 가능한 인덱스를 만들 뿐만 아니라 추출된 데이터 자산을 Azure Storage의 지식 저장소 에 유지할 수 있습니다.

인덱서는 지식 저장소에 다음과 같은 종류의 자산을 저장할 수 있습니다.

  • 필드 값의 테이블입니다.
  • 문서에서 추출된 이미지입니다.
  • 데이터 구조를 나타내는 JSON 문서; 필드 및 값의 복잡한 계층 구조일 수 있습니다.
